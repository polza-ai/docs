Claude Code — официальный CLI-инструмент от Anthropic для работы с кодом прямо из терминала. Он умеет читать и редактировать файлы, запускать команды, работать с git и решать сложные задачи в несколько шагов.

## Требования

* macOS, Linux, Windows (WSL) или Windows (нативно)
* Node.js 18 или новее
* API-ключ [polza.ai](https://polza.ai/dashboard/api-keys)

## Установка Claude Code

```bash
npm install -g @anthropic-ai/claude-code
```

Или через официальный установщик (только macOS / Linux / WSL):

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

## Подключение к Polza.AI

Claude Code использует стандартный Anthropic API. Достаточно указать URL Polza в качестве базового адреса.

<Tabs>
  <Tab title="macOS / Linux / WSL">

<Steps>
  <Step title="Откройте профиль оболочки">
    ```bash
    nano ~/.zshrc   # zsh (macOS по умолчанию)
    # или
    nano ~/.bashrc  # bash
    ```
  </Step>
  <Step title="Добавьте переменные окружения">
    ```bash
    export ANTHROPIC_BASE_URL="https://polza.ai/api"
    export ANTHROPIC_AUTH_TOKEN="ваш-api-ключ"
    export ANTHROPIC_API_KEY=""  # Важно: оставьте пустым
    export ANTHROPIC_MODEL="anthropic/claude-sonnet-4.6"  # Модель, на которой пойдёт сессия
    ```

    <Note>
      `ANTHROPIC_MODEL` — только основная модель сессии. Claude Code — агентная система и **делегирует** часть работы другим моделям (`CLAUDE_CODE_SUBAGENT` и др.), поэтому одной переменной недостаточно — полный список моделей для делегирования настраивается в секции [Настройка моделей](/integracii/claude-code#настройка-моделей).
    </Note>

    Замените `ваш-api-ключ` на ключ из [личного кабинета](https://polza.ai/dashboard/api-keys),
    а `anthropic/claude-sonnet-4.6` — на любую модель из [каталога](https://polza.ai/models).
  </Step>
  <Step title="Перезапустите терминал">
    ```bash
    source ~/.zshrc
    ```
  </Step>
  <Step title="Запустите Claude Code">
    ```bash
    cd /path/to/your/project
    claude
    ```
  </Step>
</Steps>

На Windows Claude Code работает без WSL — через **cmd.exe** или PowerShell. Рекомендуем задавать переменные окружения через `settings.json` (проще и надёжнее) или через системные переменные Windows.

<Tabs>
  <Tab title="Через settings.json (рекомендуется)">

Создайте или откройте файл `%USERPROFILE%\.claude\settings.json` и добавьте:

```json
{
  "model": "anthropic/claude-sonnet-4.6",
  "env": {
    "ANTHROPIC_BASE_URL": "https://polza.ai/api",
    "ANTHROPIC_AUTH_TOKEN": "ваш-api-ключ",
    "ANTHROPIC_API_KEY": ""
  }
}
```

Замените `ваш-api-ключ` на ключ из [личного кабинета](https://polza.ai/dashboard/api-keys),
а `anthropic/claude-sonnet-4.6` — на любую модель из [каталога](https://polza.ai/models).

Обратите внимание на уровни вложенности: `model` — поле верхнего уровня, рядом с `env`, а не внутри него.

Это самый простой способ — ничего больше настраивать не нужно. Запустите проект:

```cmd
cd C:\path\to\your\project
claude
```

  </Tab>
  <Tab title="Через системные переменные (cmd.exe)">

Откройте **cmd.exe** и выполните:

```cmd

setx ANTHROPIC_API_KEY ""
setx ANTHROPIC_MODEL "anthropic/claude-sonnet-4.6"
```

<Warning>
`setx` записывает переменные постоянно, но они применяются только в **новом** окне cmd.exe. Текущую сессию нужно перезапустить.
</Warning>

После перезапуска cmd.exe:

```cmd
cd C:\path\to\your\project
claude
```

Перезапустите PowerShell, затем:


Некоторые функции Claude Code (интерактивный ввод, цвета терминала) работают лучше в **cmd.exe**, чем в PowerShell. Если возникают проблемы с интерфейсом — запускайте через cmd.exe.
</Note>

## Настройка моделей

Модель в Claude Code задаётся на трёх независимых уровнях — их легко перепутать:

* **Основная модель сессии** — то, чем вы работаете по умолчанию. Задаётся полем `model` в `settings.json` или переменной `ANTHROPIC_MODEL`.
* **Раскрытие алиасов** `opus`, `sonnet`, `haiku` — переменные `ANTHROPIC_DEFAULT_*_MODEL`. Они срабатывают только там, где модель выбрана именно алиасом: `/model opus`, режим планирования, определения субагентов.
* **Модель субагентов** — `CLAUDE_CODE_SUBAGENT_MODEL`.

<Warning>
`ANTHROPIC_DEFAULT_OPUS_MODEL`, `ANTHROPIC_DEFAULT_SONNET_MODEL` и `ANTHROPIC_DEFAULT_HAIKU_MODEL` **не задают модель сессии**. Если прописать только их, Claude Code запустится на своей модели по умолчанию, а слаг Polza будет проигнорирован — молча, без ошибки.
</Warning>

<Tabs>
  <Tab title="macOS / Linux / WSL">
    ```bash
    export ANTHROPIC_MODEL="anthropic/claude-sonnet-4.6"
    export ANTHROPIC_DEFAULT_SONNET_MODEL="anthropic/claude-sonnet-4.6"
    export ANTHROPIC_DEFAULT_OPUS_MODEL="anthropic/claude-opus-4.6"
    export ANTHROPIC_DEFAULT_HAIKU_MODEL="anthropic/claude-haiku-4.5"
    export CLAUDE_CODE_SUBAGENT_MODEL="anthropic/claude-sonnet-4.6"
    ```
  </Tab>
  <Tab title="Windows (cmd.exe)">
    ```cmd
    setx ANTHROPIC_MODEL "anthropic/claude-sonnet-4.6"
    setx ANTHROPIC_DEFAULT_SONNET_MODEL "anthropic/claude-sonnet-4.6"
    setx ANTHROPIC_DEFAULT_OPUS_MODEL "anthropic/claude-opus-4.6"
    setx ANTHROPIC_DEFAULT_HAIKU_MODEL "anthropic/claude-haiku-4.5"
    setx CLAUDE_CODE_SUBAGENT_MODEL "anthropic/claude-sonnet-4.6"
    ```
  </Tab>
  <Tab title="Windows (settings.json)">
    ```json
    {
      "model": "anthropic/claude-sonnet-4.6",
      "env": {
        "ANTHROPIC_BASE_URL": "https://polza.ai/api",
        "ANTHROPIC_AUTH_TOKEN": "ваш-api-ключ",
        "ANTHROPIC_API_KEY": "",
        "ANTHROPIC_DEFAULT_SONNET_MODEL": "anthropic/claude-sonnet-4.6",
        "ANTHROPIC_DEFAULT_OPUS_MODEL": "anthropic/claude-opus-4.6",
        "ANTHROPIC_DEFAULT_HAIKU_MODEL": "anthropic/claude-haiku-4.5",
        "CLAUDE_CODE_SUBAGENT_MODEL": "anthropic/claude-sonnet-4.6"
      }
    }
    ```
  </Tab>
</Tabs>

| Параметр | Применяется для |
| --- | --- |
| `model` (поле `settings.json`) | Основная модель сессии |
| `ANTHROPIC_MODEL` | Основная модель сессии, вариант через переменную окружения |
| `ANTHROPIC_DEFAULT_SONNET_MODEL` | Раскрытие алиаса `sonnet` |
| `ANTHROPIC_DEFAULT_OPUS_MODEL` | Раскрытие алиаса `opus` |
| `ANTHROPIC_DEFAULT_HAIKU_MODEL` | Раскрытие алиаса `haiku` и фоновые служебные вызовы |
| `CLAUDE_CODE_SUBAGENT_MODEL` | Субагенты внутри сессии |

Полный список доступных моделей — в [каталоге](https://polza.ai/models).

<Note>
Встроенные идентификаторы Anthropic — `claude-sonnet-4-5-20250929`, `claude-opus-4-8[1m]`, `claude-haiku-4-5` — Polza принимает и сопоставляет с моделями каталога сама. Незаданная переменная больше не роняет субагентов и фоновые вызовы с ошибкой «модель не найдена», но такой запрос уйдёт на **модель Anthropic** и спишется по её цене, а не по цене выбранного вами слага. Хотите работать на другой модели — задайте все параметры из таблицы выше.
</Note>

### Приоритет выбора модели

Если модель задана несколькими способами сразу, побеждает тот, что выше в списке:

1. `/model <слаг>` внутри сессии
2. флаг `claude --model <слаг>` при запуске
3. переменная `ANTHROPIC_MODEL`
4. поле `model` в `settings.json`
5. модель по умолчанию — переменная `ANTHROPIC_DEFAULT_MODEL`, а если её нет, то модель аккаунта. Сюда вы попадаете, если не задали ничего из перечисленного выше

<Note>
Быстрая проверка без правки конфигов: выполните `/model anthropic/claude-sonnet-4.6` прямо в сессии или запустите `claude --model anthropic/claude-sonnet-4.6`. Команда `/model` дополнительно сохраняет выбор как поле `model` в пользовательских настройках.
</Note>

<Warning>
Не задавайте одну и ту же модель двумя способами: `ANTHROPIC_MODEL` перебивает поле `model`, и при расхождении вы будете править не тот параметр, который реально работает. Выберите что-то одно.
</Warning>

## Настройка через settings.json

Альтернативно настройте подключение через файл конфигурации — это работает на всех платформах без изменения переменных окружения.

| Платформа | Путь к файлу |
| --- | --- |
| macOS / Linux | `~/.claude/settings.json` |
| Windows | `%USERPROFILE%\.claude\settings.json` |
| Проект (все ОС) | `.claude/settings.local.json` |

```json
{
  "model": "anthropic/claude-sonnet-4.6",
  "env": {
    "ANTHROPIC_BASE_URL": "https://polza.ai/api",
    "ANTHROPIC_AUTH_TOKEN": "ваш-api-ключ",
    "ANTHROPIC_API_KEY": ""
  }
}
```

<Warning>
Следите за уровнем вложенности. Переменные окружения работают **только внутри** блока `env` — на верхнем уровне файла Claude Code игнорирует их молча, без ошибки и предупреждения. Поле `model`, наоборот, работает **только на верхнем уровне**, рядом с `env`.
</Warning>

После правки конфига полностью закройте и заново запустите `claude`: переменные окружения и `settings.json` читаются один раз, при старте.

<Warning>
Не добавляйте `settings.local.json` с API-ключом в git-репозиторий. Добавьте файл в `.gitignore`.
</Warning>

## Проверка подключения

После запуска выполните команду `/status` внутри сессии:

```
> /status
Auth token:          ANTHROPIC_AUTH_TOKEN
Anthropic base URL:  https://polza.ai/api
Model:               anthropic/claude-sonnet-4.6
```

В строке `Model` должен стоять слаг Polza — значит сессия действительно идёт на выбранной модели, а не только авторизация.

<Warning>
Если в строке модели написано `Model: Default (claude-…)`, выбранная модель **не применилась**. Подключение при этом рабочее — базовый URL и ключ подхватились, — но запросы уходят на модель Claude Code по умолчанию. Разбор причин — в блоке [Решение проблем](#решение-проблем).
</Warning>

## Решение проблем

<AccordionGroup>
  <Accordion title="Ошибка аутентификации (401)">
    * Убедитесь что `ANTHROPIC_AUTH_TOKEN` содержит ваш ключ Polza
    * Проверьте что `ANTHROPIC_API_KEY` явно установлен в пустую строку (`""`)
    * Если ранее выполняли вход через Anthropic — выполните `/logout` внутри Claude Code
  </Accordion>
  <Accordion title="Запросы идут в Polza, но работает не та модель">
    Признаки: в `/status` строка `Model: Default (claude-…)`, в приветственном экране — не тот слаг, который вы задавали. Ключ при этом принимается и баланс расходуется, ошибок нигде нет.

    Проверьте по порядку:

    * **Модель вообще не задана.** Нужны поле `model` в `settings.json` или переменная `ANTHROPIC_MODEL` — см. [Настройка моделей](#настройка-моделей)
    * **Вы понадеялись на `ANTHROPIC_DEFAULT_*_MODEL`.** Эти переменные задают только раскрытие алиасов `opus` / `sonnet` / `haiku` и не выбирают модель сессии
    * **Поле лежит не на том уровне.** `model` — на верхнем уровне `settings.json`, переменные окружения — внутри блока `env`
    * **Claude Code не перезапущен.** Конфиг читается только при старте — закройте сессию полностью и откройте заново

    Быстрая проверка, что дело именно в конфиге: выполните `/model anthropic/claude-sonnet-4.6` прямо в сессии. Если модель переключилась — правьте конфиг, слаг и доступ к модели в порядке.
  </Accordion>
  <Accordion title="Claude Code не видит переменные окружения">
    * **macOS / Linux:** перезапустите терминал после изменения профиля оболочки, проверьте: `echo $ANTHROPIC_BASE_URL`
    * **Windows (setx):** `setx` применяется только в **новом** окне cmd.exe — текущую сессию нужно закрыть и открыть заново
    * **Windows (PowerShell):** переменные могут не передаваться в дочерние процессы — используйте `settings.json` вместо профиля PowerShell
    * **`settings.json`:** переменные должны лежать внутри блока `env`. На верхнем уровне файла Claude Code их не читает и об этом не сообщает
    * Самый надёжный способ на любой платформе — прописать переменные в `~/.claude/settings.json` (macOS/Linux) или `%USERPROFILE%\.claude\settings.json` (Windows)
  </Accordion>
  <Accordion title="Проблемы с интерфейсом на Windows (цвета, ввод, артефакты)">
    Claude Code лучше работает в **cmd.exe**, чем в PowerShell. Если интерфейс отображается с артефактами или не реагирует на клавиши:

    * Запускайте `claude` из **cmd.exe**, а не из PowerShell или Windows Terminal с PowerShell-профилем
    * В Windows Terminal можно добавить профиль cmd.exe и запускать сессии через него
    * Как альтернатива — использовать WSL с bash/zsh
  </Accordion>
  <Accordion title="Статус-бар показывает ₽0.00">
    * Проверьте что `ANTHROPIC_BASE_URL` и `ANTHROPIC_AUTH_TOKEN` передаются скрипту
    * Стоимость обновляется только после завершения запроса — в процессе генерации показывается предыдущее значение
    * Проверьте что в папке проекта нет `.claude/settings.json` с другим статус-скриптом
    * **Windows:** используйте полный путь к `node.exe` (например `C:\\Program Files\\nodejs\\node.exe`) — Claude Code запускает скрипт без стандартного `PATH`, поэтому просто `node` не работает. Узнать путь: `where node` в cmd.exe
  </Accordion>
  <Accordion title="Ошибка модели (model not found)">
    * Убедитесь что модель доступна в [каталоге Polza](https://polza.ai/models)
    * Проверьте правильность написания ID модели (например, `anthropic/claude-sonnet-4.6`)
    * Ошибка приходит не из основного чата, а из субагента (`Agent … failed: … API Error: 400`) — значит субагент или фоновый вызов запрашивает модель, которой нет в каталоге. Задайте `CLAUDE_CODE_SUBAGENT_MODEL` и `ANTHROPIC_DEFAULT_*_MODEL` слагами Polza — см. [Настройка моделей](#настройка-моделей)
  </Accordion>
</AccordionGroup>
