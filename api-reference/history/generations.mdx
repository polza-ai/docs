## Авторизация

Эндпоинт поддерживает авторизацию:

| Тип | Видимость |
|-----|-----------|
| **API ключ** (`pza_...`) | Только генерации этого ключа |

## Параметры запроса

### Пагинация

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `page` | integer | 1 | Номер страницы (от 1) |
| `limit` | integer | 20 | Количество записей на странице (1-100) |

### Фильтрация

| Параметр | Тип | Описание |
|----------|-----|----------|
| `dateFrom` | string | Дата начала периода (ISO 8601) |
| `dateTo` | string | Дата конца периода (ISO 8601) |
| `requestType` | string | Тип запроса: chat, image, video, audio |
| `status` | string | Статус: completed, failed, pending |
| `apiKeyId` | string | ID API ключа (только при JWT авторизации) |
| `withoutApiKey` | boolean | Показать генерации без API ключа (только JWT) |

### Сортировка

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `sortBy` | string | createdAt | Поле: createdAt, clientCost |
| `sortOrder` | string | desc | Направление: asc, desc |

## Примеры

<CodeGroup>
```bash Все генерации
curl "https://polza.ai/api/v1/history/generations" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```bash С фильтрацией
curl "https://polza.ai/api/v1/history/generations?requestType=chat&status=completed&dateFrom=2025-01-01T00:00:00Z&limit=50" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    'https://polza.ai/api/v1/history/generations',
    headers={'Authorization': 'Bearer YOUR_API_KEY'},
    params={
        'requestType': 'chat',
        'status': 'completed',
        'page': 1,
        'limit': 20,
        'sortBy': 'createdAt',
        'sortOrder': 'desc'
    }
)

data = response.json()
for item in data['items']:
    print(f"{item['model']}: {item['cost']} руб.")
```
</CodeGroup>

## Поля элемента

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | ID генерации |
| `model` | string | Slug модели |
| `modelDisplayName` | string | Отображаемое имя модели |
| `requestType` | string | Тип: chat, image, video, audio |
| `provider` | string\|null | Провайдер, обработавший запрос |
| `status` | string | Статус: completed, failed, pending |
| `cost` | string | Стоимость в рублях |
| `usage` | object\|null | Использование токенов |
| `generationTimeMs` | number\|null | Время генерации в миллисекундах |
| `createdAt` | string | Дата создания |
| `apiKeyName` | string | Имя API ключа (при JWT авторизации) |
| `apiKeyShort` | string | Последние 6 символов ключа |
| `stepsCount` | number | Число шагов модели — только у запросов с [серверными инструментами](/gaidy/server-tools) |
| `webSearch` | object | Веб-поиск запроса (все шаги): `requests` — число выполненных поисков, `costRub` — их стоимость, ₽. Есть, если поиск выполнялся |

Запрос с серверными инструментами — одна запись: `cost` и `usage` — итог по всем шагам. Шаги — через [`/children`](#get-шаги-запроса).

## GET Детали генерации

```
GET /v1/history/generations/{id}
```

Возвращает подробную информацию о конкретной генерации.

### Пример

```bash
curl "https://polza.ai/api/v1/history/generations/gen_581761234567890123" \
  -H "Authorization: Bearer YOUR_API_KEY"
```


### Поля ответа

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | ID генерации |
| `organizationId` | string | ID организации |
| `apiKeyId` | string | ID API ключа |
| `unifiedModelId` | string | ID модели |
| `requestType` | string | Тип запроса |
| `apiType` | string | Тип API (chat_completions, responses, media и т.д.) |
| `responseMode` | string | Режим ответа (sync, stream, async) |
| `status` | string | Статус генерации |
| `finishReason` | string | Причина завершения (stop, length, tool_calls и т.д.) |
| `finalEndpointSlug` | string | Провайдер |

| `clientCost` | string | Стоимость (RUB) |
| `generationTimeMs` | number\|null | Время генерации (ms) |

| `stepsCount` | number | Для запроса с серверными инструментами — число шагов |
| `serverTools` | object\|null | Для запроса с серверными инструментами — итоги: `steps`, `promptTokens`, `completionTokens`, `clientCostRub`, `serverToolsCostRub`, `serverToolUse`, `toolCallsRequested`, `toolCallsExecuted` |

## GET Шаги запроса

```
GET /v1/history/generations/{id}/children
```

Шаги запроса с [серверными инструментами](/gaidy/server-tools) по порядку. `{id}` — id запроса (`polza.parent_generation_id` из ответа API).

### Пример

```bash
curl "https://polza.ai/api/v1/history/generations/gen_2216206771127209985/children" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Ответ (200)

```json

    "id": "gen_2216206770787471361",
    "model": "openai/gpt-5.2",
    "requestType": "chat",
    "status": "completed",
    "cost": "0.0022",
    "usage": { "prompt_tokens": 12, "completion_tokens": 8, "total_tokens": 20 },
    "parentGenerationId": "gen_2216206771127209985",
    "stepIndex": 1,
    "serverTools": []
  },
  {
    "id": "gen_2216206771244650497",
    "model": "openai/gpt-5.2",
    "requestType": "chat",
    "status": "completed",
    "cost": "0.51735",
    "usage": { "prompt_tokens": 15, "completion_tokens": 83, "total_tokens": 98 },
    "parentGenerationId": "gen_2216206771127209985",
    "stepIndex": 2,
    "serverTools": [
      {
        "type": "polza:web_search",
        "status": "completed",
        "costRub": "0.5",
        "latencyMs": 10,
        "metadata": { "callId": "call_1790688870318", "engine": "yandex", "resultsCount": 2, "status": "completed" }
      }

```

Элементы — в формате списка генераций, плюс поля шага:

| Поле | Тип | Описание |
|------|-----|----------|
| `parentGenerationId` | string | Id запроса |
| `stepIndex` | number | Номер шага, с 1 |
| `serverTools` | array | Инструменты, результаты которых получил шаг: `type`, `status` (`completed`, `failed`), `costRub`, `latencyMs`, `metadata`. Их стоимость входит в `cost` шага |

Лог запроса (`GET /v1/history/generations/{id}/log`) по id запроса отдаёт лог последнего шага; логи остальных шагов — по их id.
