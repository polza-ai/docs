Polza.AI добавляет веб-поиск к любой модели — от GPT-5 до Claude и Gemini. Модель получает актуальные данные из интернета, а вы — ответ со ссылками на источники.

## Быстрый старт

### Chat Completions API

Самый простой способ — плагин `web`: Polza ищет по вашему сообщению до вызова модели, бесплатно и с любой моделью. Чтобы модель сама решала, что и сколько раз искать, используйте серверный инструмент `polza:web_search` — см. [Два режима поиска](#два-режима-поиска).

<CodeGroup>
```typescript TypeScript
import OpenAI from 'openai';

const openai = new OpenAI({
  baseURL: 'https://polza.ai/api/v1',
  apiKey: '<POLZA_AI_API_KEY>'
});

const completion = await openai.chat.completions.create({
  model: 'openai/gpt-5.2',
  messages: [
    { role: 'user', content: 'Последние новости о квантовых компьютерах' }
  ],
  // @ts-ignore — plugins не входит в типы OpenAI SDK
  plugins: [{ id: 'web' }]
});

console.log(completion.choices[0].message.content);
console.log(completion.choices[0].message.annotations); // ссылки на источники
```

```python Python
from openai import OpenAI

client = OpenAI(
    base_url="https://polza.ai/api/v1",
    api_key="<POLZA_AI_API_KEY>"
)

completion = client.chat.completions.create(
    model="openai/gpt-5.2",
    messages=[
        {"role": "user", "content": "Последние новости о квантовых компьютерах"}
    ],
    extra_body={
        "plugins": [{"id": "web"}]
    }
)

print(completion.choices[0].message.content)
print(completion.choices[0].message.annotations)  # ссылки на источники
```

```bash cURL
curl -X POST "https://polza.ai/api/v1/chat/completions" \
  -H "Authorization: Bearer <POLZA_AI_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5.2",
    "messages": [
      {"role": "user", "content": "Последние новости о квантовых компьютерах"}
    ],
    "plugins": [{"id": "web"}]
  }'
```
</CodeGroup>

### Responses API

Используйте `tools` с типом `web_search_preview` (или `web_search`). В `output` придут элемент поиска и элемент `message` с ответом:

<CodeGroup>
```typescript TypeScript
const response = await fetch('https://polza.ai/api/v1/responses', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer <POLZA_AI_API_KEY>',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    model: 'openai/gpt-5.2',
    input: 'Последние новости о квантовых компьютерах',
    tools: [{ type: 'web_search_preview' }]
  })
});

const data = await response.json();
const message = data.output.find((item) => item.type === 'message');
console.log(message.content[0].text);
console.log(message.content[0].annotations); // ссылки на источники
```

```python Python
import requests

response = requests.post(
    'https://polza.ai/api/v1/responses',
    headers={'Authorization': 'Bearer <POLZA_AI_API_KEY>'},
    json={
        'model': 'openai/gpt-5.2',
        'input': 'Последние новости о квантовых компьютерах',
        'tools': [{'type': 'web_search_preview'}]
    }
)

data = response.json()
message = next(item for item in data['output'] if item['type'] == 'message')
print(message['content'][0]['text'])
print(message['content'][0]['annotations'])  # ссылки на источники
```

```bash cURL
curl -X POST "https://polza.ai/api/v1/responses" \
  -H "Authorization: Bearer <POLZA_AI_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5.2",
    "input": "Последние новости о квантовых компьютерах",
    "tools": [{"type": "web_search_preview"}]
  }'
```
</CodeGroup>

## Два режима поиска

Поиск всегда выполняет Polza — поисковиком Яндекса (по умолчанию) или Google. Провайдеру модели поиск не передаётся, поэтому он одинаково работает с любой моделью и в любом формате API.

| | Серверный инструмент `polza:web_search` | Плагин `web` |
|--|--|--|
| Кто решает, искать ли | Модель: может не искать или искать несколько раз, уточняя запрос | Polza ищет всегда, один раз до вызова модели |
| Что ищется | Запросы, которые формулирует модель | Ваше последнее сообщение или `search_prompt` |
| Модели | С поддержкой вызова функций | Любые |
| Свежесть | Модель может искать только результаты за день, неделю, месяц или год и видит дату публикации | Без ограничения по дате |
| Цена поиска | 0,50 ₽ за выполненный поиск | Бесплатно |
| Подробнее | [Серверные инструменты](/gaidy/server-tools) | [Настройки плагина](#настройки-плагина-web) |

В обоих режимах результаты поиска увеличивают `prompt_tokens`: модель читает их как часть запроса.

## Как включить

| Способ | API | Режим |
|--------|-----|-------|
| `tools: [{"type": "polza:web_search"}]` | Chat Completions, Responses, Anthropic Messages, Gemini | Серверный инструмент |
| `web_search_options: {}` | Chat Completions | Серверный инструмент |
| `tools: [{"type": "web_search"}]` (и `web_search_preview`) | Responses | Серверный инструмент |
| `tools: [{"type": "web_search_20250305", "name": "web_search"}]` | Anthropic Messages | Серверный инструмент |
| `tools: [{"googleSearch": {}}]` | Gemini | Серверный инструмент |
| `plugins: [{"id": "web"}]` | Chat Completions, Responses | Плагин `web` |

Если модель не поддерживает вызов функций, родные параметры поиска (`web_search_options`, `web_search`, `web_search_20250305`, `googleSearch`) и `polza:web_search` работают как плагин `web`: Polza ищет до вызова модели, запрос не отклоняется.

Из параметров родных форматов учитываются только `max_uses`, `allowed_domains` и `blocked_domains` инструмента Anthropic. `search_context_size`, `user_location` и `filters` принимаются для совместимости, но на поиск не влияют — чтобы управлять поиском, используйте `polza:web_search` с [параметрами](/gaidy/server-tools#параметры-инструментов).

<Note>
Плагин `web` можно передать вместе с серверными инструментами. Тогда поиск по вашему сообщению выполняется один раз в начале запроса, а его результаты модель видит на каждом шаге.
</Note>

## Формат ответа

### Chat Completions API

Источники возвращаются в поле `annotations`:

```json
{
  "choices": [{
    "message": {
      "role": "assistant",
      "content": "По данным ЦБ, официальный курс доллара на сегодня — ...",
      "annotations": [
        {
          "type": "url_citation",
          "url_citation": {
            "url": "https://example.com/usd-rate",
            "title": "Официальные курсы валют",
            "content": "Выдержка из страницы...",
            "start_index": 0,
            "end_index": 0
          }
        }
      ]
    }
  }]
}
```

### Поля аннотации

| Поле | Тип | Описание |
|------|-----|----------|
| `type` | string | Всегда `"url_citation"` |
| `url_citation.url` | string | URL источника |
| `url_citation.title` | string | Заголовок страницы |
| `url_citation.content` | string | Выдержка из страницы, которую получила модель |
| `url_citation.start_index` | number | Всегда `0`: привязки источника к месту в тексте ответа нет |
| `url_citation.end_index` | number | Всегда `0` |

`annotations` содержат все найденные источники, а не только те, на которые модель сослалась в тексте.

### Responses API

Поиск виден отдельным элементом `output` перед сообщением модели. При родном `web_search` это `web_search_call`, при `polza:web_search` — элемент с типом `polza:web_search` (см. [Серверные инструменты](/gaidy/server-tools#другие-форматы-api)). Источники — в `annotations` сообщения:

```json
{
  "output": [
    {
      "type": "web_search_call",
      "id": "call_1790688925812",
      "status": "completed",
      "action": {
        "type": "search",
        "query": "курс доллара ЦБ сегодня",
        "sources": [
          { "url": "https://example.com/usd-rate", "title": "Официальные курсы валют" }
        ]
      }
    },
    {
      "type": "message",
      "role": "assistant",
      "status": "completed",
      "content": [{
        "type": "output_text",
        "text": "По данным ЦБ, ...",
        "annotations": [
          {
            "type": "url_citation",
            "url": "https://example.com/usd-rate",
            "title": "Официальные курсы валют",
            "start_index": 0,
            "end_index": 0,
            "url_citation": { "url": "https://example.com/usd-rate", "title": "Официальные курсы валют", "content": "...", "start_index": 0, "end_index": 0 }
          }
        ]
      }]
    }
  ]
}
```

Если модель не поддерживает вызов функций, родной `web_search` выполняется как плагин `web`: `web_search_call` содержит в `action.sources` только адреса (`{"type": "url", "url": "..."}`) без `query`, а в стриме приходит после сообщения модели. С `plugins: [{"id": "web"}]` элемента поиска в `output` нет — источники только в `annotations`.

### Anthropic Messages и Gemini

- **Anthropic Messages** — блоки `server_tool_use` и `web_search_tool_result`, источники — в `citations` текстового блока. В режиме плагина `web` блоков поиска нет, только `citations`.
- **Gemini** — источники в `groundingMetadata.groundingChunks`.

## Настройки плагина `web`

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `max_results` | number | 5 | Сколько результатов добавить в запрос: от 1 до 20 (для Google — до 10) |
| `search_prompt` | string | — | Поисковый запрос. Если не задан, ищется текст вашего последнего сообщения |
| `engine` | string | `yandex` | Поисковик: `yandex` или `google`. Другие значения (в том числе `native` и `exa`) — поиск Яндексом |
| `enabled` | boolean | true | Включить/выключить плагин |

### Пример с настройками

```json
{
  "model": "google/gemini-2.5-pro",
  "messages": [
    {"role": "user", "content": "Сравни последние релизы NVIDIA и AMD"}
  ],
  "plugins": [{
    "id": "web",
    "engine": "google",
    "max_results": 3,
    "search_prompt": "Новости NVIDIA AMD GPU"
  }]
}
```

## Usage и стоимость

В обоих режимах число выполненных поисков — в `usage.server_tool_use.web_search_requests`:

```json
{
  "usage": {
    "prompt_tokens": 27,
    "completion_tokens": 91,
    "total_tokens": 118,
    "server_tool_use": {
      "web_search_requests": 1
    },
    "cost_rub": 0.51955,
    "cost": 0.51955,
    "cost_details": {
      "inference_cost_rub": 0.01955,
      "server_tools_cost_rub": 0.5
    }
  }
}
```

- **Серверный инструмент** — 0,50 ₽ за выполненный поиск, в `cost_details.server_tools_cost_rub`. Поиск с ошибкой не оплачивается. Все поля — в разделе [Ответ](/gaidy/server-tools#ответ).
- **Плагин `web`** — поиск бесплатный, в `cost_rub` только модель.

Если поисковик не ответил, запрос не падает: инструмент возвращает модели ошибку, а плагин `web` отдаёт ответ без результатов поиска. Такой поиск не оплачивается и не попадает в счётчик.

## Советы

<AccordionGroup>
  <Accordion title="Не комбинируйте с json_object" icon="triangle-exclamation">
    Формат ответа `json_object` или `json_schema` может мешать модели включать цитаты и ссылки на источники. Если вам нужен структурированный вывод с веб-поиском, обрабатывайте текстовый ответ с аннотациями отдельно.
  </Accordion>
  <Accordion title="Используйте search_prompt для точности" icon="magnifying-glass">
    Плагин `web` ищет текст вашего последнего сообщения. Если сообщение длинное или вопрос многосоставный, задайте точный поисковый запрос в `search_prompt`.
  </Accordion>
  <Accordion title="Проверяйте annotations" icon="link">
    Наличие `url_citation` в `annotations` подтверждает, что поиск был выполнен и его результаты попали к модели. Если `annotations` пуст — поиска не было (например, модель решила, что он не нужен) или он ничего не нашёл.
  </Accordion>
  <Accordion title="Комбинация с изображениями" icon="image">
    Веб-поиск можно комбинировать с отправкой изображений. Например, отправьте фото продукта и попросите найти актуальные цены — модель выполнит поиск с учётом визуального контекста.
  </Accordion>
</AccordionGroup>
